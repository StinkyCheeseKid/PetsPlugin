# PetsPlugin

Pets Plugin 1.0.0 with eleven ModelEngine blueprints and the Pets resource pack. Use Java 21 and Paper/Purpur 1.21.11 with ModelEngine 4 installed separately. Copy plugins/ into your server plugins folder. Generate the ModelEngine resource pack and merge assets/pets from the included resource pack into it for pet menu icons and tooltips. Distribute the resulting pack to players. The included Pets pack alone does not replace the generated ModelEngine pack. Local preview-renderer behavior has not been verified to behave identically with real ModelEngine.

This repository contains the built plugin and its applicable model/resource assets.
Test servers, worlds, logs, player data, and development source are excluded.
